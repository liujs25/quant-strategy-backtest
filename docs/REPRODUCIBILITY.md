# Reproducibility

## Verify the published experiment

Python 3.12 was used on an Apple M5. The tree models and constrained allocation use CPU; earlier neural experiments used MPS. On macOS, install OpenMP before LightGBM:

```bash
brew install libomp
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-publication.txt
python -m pytest -q
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python comparison_2026/verify.py
python comparison_2026/report.py
python scripts/verify_publication.py
```

`requirements-publication.txt` pins the dependencies needed for the main comparison and all regression tests. `requirements-research-lock.txt` records the complete historical research environment; `requirements-lock.txt` records the earlier Kaggle experiment. Exact package availability and platform wheels can vary. Fixed seeds do not guarantee bitwise equality across library/BLAS versions.

The primary verifier recomputes every table metric and every pairwise confidence interval, replays both model checkpoints, and checks allocation and accounting identities. It uses published predictions and trade/equity files, without downloading market data. Report generation reads completed outputs and never selects or retrains models. `--history` additionally verifies the original complete local workspace against its historical inventory; excluded raw/intermediate files are required for that option.

## Refit the frozen comparison

The executed training code is `comparison_2026/run.py`; it refuses to overwrite a completed comparison. It uses the frozen source feature/ledger implementations in `research/engine.py` and `incremental/core.py`. The ranker is refitted at frozen parameters on training labels ending before 2024-10-01. The residual model checkpoint was fitted on that same sample and is replayed without tuning.

For full refitting, use a separate local copy. Download the provider data with the recorded scripts and verify hashes before claiming exact reproduction:

```bash
python scripts/download_research.py
python scripts/download_research.py --final
python incremental/download_holdout.py
```

The existing historical selection locks satisfy the scripts' download gates; their presence does not make the data untouched again. `incremental/download_holdout.py` refuses to overwrite existing files. Requests cover development 2010–2023, a 2023–2025 bridge, and 2026 through November 20. Provider requests, unavailable symbols and file hashes are recorded in `research/development_raw/download_manifest.json`, `research/final_raw/download_manifest.json` and `incremental/holdout_download_manifest.json`. Universe and feature-reference sets are frozen independently of final-period availability. Newly responding historical ticker strings must not enter the reference set.

In the replication copy, preserve the delivered `comparison_2026/` directory under a different name, create an empty directory at that path containing its `run.py`, `report.py` and `verify.py`, then run:

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python comparison_2026/run.py
python comparison_2026/report.py
python comparison_2026/verify.py
```

`run.py` also checks the delivered `incremental/final_predictions.pkl` to ensure residual-score agreement and identical evaluation keys. This is a consistency check against a frozen artifact, not test-based parameter selection. Provider revisions may cause the check to fail; retain and disclose the discrepancy rather than weakening it or mixing snapshots.

## Earlier studies

Their reports contain the original commands, protocols, training histories and artifact locations. They remain available for historical reproduction, not as competing current headline results. Rebuildable panel caches are generated by the corresponding study entry points. Run historical replication in separate copies: selection/final-output guards intentionally prevent overwriting completed studies.

Raw market-data downloads are not distributed. This repository publishes research outputs and audit evidence; obtaining provider data is a separate step subject to the provider's terms. The source is survivor-conditioned and lacks a verified institutional corporate-action ledger; reproducibility does not remove those data limitations.
